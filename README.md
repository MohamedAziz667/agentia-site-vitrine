## 📌 Description du projet

Ce site vitrine présente les concepts fondamentaux des **Agents IA** et de **l'Intelligence Artificielle Agentique** — un domaine en pleine expansion qui transforme les usages professionnels et personnels de l'IA.

Il a été conçu et développé en équipe dans le cadre d'un atelier de gestion de projet, avec une approche collaborative via **GitHub** et une planification sur **Trello**.

## 🚀 Lancer le site

Aucune installation requise. Il suffit de :

1. Cloner le repo :
```bash
git clone https://github.com/MohamedAziz667/agentia-site-vitrine.git
```

2. Ouvrir le fichier `index.html` dans votre navigateur.
